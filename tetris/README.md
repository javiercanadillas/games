# Tetris

This is a simple Tetris game created with HTML, CSS, and JavaScript.

## How to Play

1.  Open the `index.html` file in your web browser.
2.  Use the arrow keys to move and rotate the tetrominoes.
    -   **Left Arrow:** Move left
    -   **Right Arrow:** Move right
    -   **Down Arrow:** Move down
    -   **Up Arrow:** Rotate
3.  The goal is to clear as many lines as possible to score points and level up.

## Features

-   Score and level tracking
-   Start, stop, and pause/resume functionality
-   Difficulty selection (easy, medium, hard)
-   Motivational messages
-   Modern and visually appealing design

Enjoy the game!
